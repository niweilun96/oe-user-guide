# 快速开始

欢迎使用 **Owl Eye (OE) 枭眼预警平台**！本指南将帮助您在 **2 分钟内完成首次登录并开始使用核心功能**。  

## 1. 访问系统

在公司内网环境中，打开浏览器（推荐使用 Chrome），访问以下地址：  
[https://owleye.envision-energy.com/#/](https://owleye.envision-energy.com/#/)

> 💡 **提示**  
> - 若无法打开，请确认您已连接公司内网（或通过 VPN 接入）。  
> - VPN 账号申请及客户端安装，请通过企业微信联系 IT Helpdesk 服务台。

## 2. 登录账号

1. 在登录页面输入您的 **OA 账号**（通常为邮箱前缀，如 `san.zhang`）和密码。  
2. 点击 **【登录】** 按钮。

![系统登录页面](/public/login-page.png)

> 🔐 **安全说明**  
> - 若忘记密码，请通过企业微信联系 IT Helpdesk 服务台重置。

## 3. 选择区域站点

成功登录后，您将进入 **OE 站点选择门户（Portal）**。请根据业务归属选择对应站点：

- **全球站点（Global）**：适用于除印度以外的所有国家/地区  
- **印度站点（India）**：仅适用于印度区域  

点击 **【Go】** 按钮，系统将自动跳转至所选区域。

> 🔒 **数据隔离说明**  
> 根据 IT 信息安全政策，印度站点与全球站点数据完全隔离，无法相互访问。

![Portal 站点选择页](/public/portal_cn.png)

## 4. 首次登录：权限确认

首次使用前，请确认已完成系统权限开通（仅需一次）：

- **预警接收人 / 行动项处理人**：系统通常会自动授权。如提示无权限，请联系业务负责人确认。  
- **片区负责人 / 业务负责人 / 合规委员**：系统默认已开通权限；若人员变更，请联系产品团队更新配置。

> ✅ 权限确认完成后，您将进入 **工作台首页**。

![工作台首页](/public/desk.png)

## 5. 开始使用核心功能

根据您的角色，重点关注以下模块：

| 角色 | 推荐操作 |
|------|--------|
| **预警接收人员、行动项处理人员** | 首页 → 处理 “待确认预警项” 或 “待完成行动项” |
| **片区管理人员** | 应用中心 → 选择对应“应用模块” → 完成预警复核管理 |
| **应用管理人员** | 应用中心 → 选择对应“应用模块” → 进行预警导出与分析 |
| **模型开发人员** | 应用中心 → 选择“试运行模块” → 查询试运行结果 |
