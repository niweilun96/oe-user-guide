# 产品简介：Owl Eye (OE) 枭眼预警平台

## 一、什么是 OE？

**Owl Eye (OE) 枭眼预警平台** 是一套基于AI人工智能、视觉算法与流程自动化数据集成的**质量与合规风险**主动探测平台。<br>

系统通过对接 Maximo、MES 等业务源，**自动采集图像、文档、APQP 交付物等关键过程数据**，利用 AI 算法模型实时识别异常，并将预警精准推送至责任人，实现“**问题早发现、责任快落实、闭环可追踪**”。
