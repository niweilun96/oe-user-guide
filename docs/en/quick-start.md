# Quick Start

Welcome to the **Owl Eye Alert Platform**! This guide will help you **complete your first login and start using core features within 2 minutes**.

## 1. Access the System

From the company intranet, open your browser (Chrome is recommended) and go to:  
[https://owleye.envision-energy.com/#/](https://owleye.envision-energy.com/#/)

> 💡 **Tip**  
> - If the page fails to load, please ensure you are connected to the company intranet (or connected via VPN).  
> - For VPN account requests or client installation, contact the IT Helpdesk via WeCom.

## 2. Log In

1. On the login page, enter your **OA account** (usually your email prefix, e.g., `san.zhang`) and password.  
2. Click the **【Log In】** button.

![Login Page](/public/login-page.png)

> 🔐 **Security Note**  
> - If you forget your password, contact the IT Helpdesk via WeCom for a reset.

## 3. Select Your Regional Site

After successful login, you will be directed to the **Owl Eye Site Selection Portal**. Please select the site that matches your business region:

- **Global Site**: For all countries/regions except India  
- **India Site**: For India operations only  

Click the **【Go】** button to be automatically redirected to your selected site.

> 🔒 **Data Isolation Notice**  
> Per IT information security policy, data between the India Site and Global Site is fully isolated and cannot be accessed across regions.

![Site Selection Portal](/public/portal_en.png)

## 4. First-Time Login: Permission Confirmation

Before your first use, please confirm that system permissions have been granted (one-time setup):

- **Alert Recipients / Action Item Assignees**: Permissions are usually auto-provisioned. If you see a “no access” message, please contact your business owner for confirmation.  
- **Regional Owners / Business Owners / Compliance Committee Members**: Permissions are enabled by default. If personnel changes occur, please contact the product team to update configurations.

> ✅ Once permissions are confirmed, you will be redirected to the **Workbench Home Page**.

![Workbench Home Page](/public/desk-en.png)

## 5. Start Using Core Features

Based on your role, focus on the following modules:

| Role | Recommended Actions |
|------|---------------------|
| **Alert Recipients / Action Item Assignees** | Home → Handle **"Alerts to be confirmed"** or **"Action items"** |
| **Regional Managers** | **Alert Application Center** → Select relevant application → Perform alert review and management |
| **Application Owners** | **Alert Application Center** → Select relevant application → Export and analyze alerts |
| **Model Developers** | **Alert Application Center** → Select **"Pilot Run Module"** → Query pilot run results |
